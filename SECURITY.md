# Security Policy

## Supported Project Type

This repository contains a frontend portfolio application built with React and Vite. It does not include a backend service or authentication system.

## Reporting a Vulnerability

If you find a security issue in this project, please do not post sensitive details publicly in an issue.

Please report it responsibly by contacting the repository owner directly and include:

- a short description of the issue
- steps to reproduce it
- potential impact
- any suggested fix, if available

## Security Notes

- Do not commit secrets, API keys, or personal credentials to this repository.
- Keep any future environment variables in local `.env` files only.
- Review third-party dependencies regularly before deployment.
